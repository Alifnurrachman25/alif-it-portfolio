# Portofolio IT Alif — React + Vite

## Fitur

- Light/dark mode; pilihan tema diingat di perangkat pengunjung.
- Foto profil di atas judul hero, animasi masuk dan animasi saat scroll.
- Profil, pendidikan, keahlian, pengalaman, dan enam proyek.
- Filter proyek dan detail proyek dalam dialog.
- Galeri enam sertifikat (BNSP, MTCNA, dua sertifikat Cisco, deployment TLab, magang), pratinjau dua halaman BNSP, dan unduh berkas asli.
- Tombol unduh CV dan tautan GitHub, LinkedIn, WhatsApp, serta email.
- Tampilan responsif dan dukungan pengurangan animasi sesuai pengaturan perangkat.

## Jalankan di komputer

1. Ekstrak ZIP, lalu buka folder `alif-it-portfolio-react` di VS Code.
2. Gunakan Node.js versi 22.13 atau lebih baru.
3. Buka terminal di folder yang berisi `package.json`.
4. Jalankan:

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan terminal. Untuk menghentikan server, tekan Ctrl+C. Jangan membuka `index.html` dengan klik dua kali; aplikasi perlu dijalankan melalui server Vite.
